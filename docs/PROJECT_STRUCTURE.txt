================================================================================
e_core – projekt struktura (src kontener + overrides)
================================================================================

Cel
----
- Gyors tajekozodas: melyik mappa mit tartalmaz.
- Egyertelmu szerkesztesi hatar:
  - platform/belso kod: `src/`
  - ugyfel testreszabas: `overrides/`

Gyoker konyvtarak szerepe
-------------------------
src/                Belső platform kod (bridge, client, server, libs, imports, locales,
                    standalone config + usableitem).
overrides/          Testreszabasi pontok (inventory/progress/core override-ok).
html/               NUI output (web build + css/img).
web/                Svelte/TS NUI forraskod.
docs/               Belső projekt dokumentacio.
tech_docs/          Helykitöltő: későbbi Docusaurus (vagy) publikus webdoksi; lásd tech_docs/README.md
types/              LuaLS stubok.
scripts/            CI/dev seged script.
_installation_assist/ Opcionális telepitesi segedanyag.

Fobb gyoker fajlok
------------------
fxmanifest.lua      Resource manifest, script betoltesi sorrend.
README.md
README_HU.md
changelog.md
export_examples_client.md
export_examples_server.md

Reszletek
---------
src/bridge/
  Keretrendszer-illesztes: esx/, qb/, global/, framework_config.lua, main.lua.

src/client/
  Kliens oldali runtime: main, exports, web/NUI bridge, integrity bridge.

src/server/
  Szerver oldali domain: meta, labor, db, exports, diagnostics, admin bridge.

src/libs/
  Közös helper modulok (`hf`, `errors`, `meta`, `config_check`).

src/imports/
  Include-olhato segedfajlok kulso resource-oknak (`core.lua`, `locale.lua`, stb.).

src/locales/
  Forditasok.

src/standalone/config/
  Globalis Config + levels.

src/standalone/usableitem.lua
  Pelda usable item logika.

overrides/
  Felulirasok (ox_inventory, qs_inventory, avp_grid_inventory, progress/UI adapterek).
  Ezt a mappat szerkeszti elsosorban az uzemelteto/ugyfel.
