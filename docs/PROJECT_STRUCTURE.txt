================================================================================
e_core – projekt struktúra és mappa szerepek
================================================================================
Fájl helye: docs/PROJECT_STRUCTURE.txt (a resource gyökérben nincs másolat).

Cél
-----
- Gyors tájékozódás: melyik mappa mit tartalmaz és hol érdemes módosítani.
- A fa alább fájllista; új fájl vagy mappa felvételekor frissítsd a fát is.

Gyökér könyvtárak szerepe
--------------------------
bridge          Keretrendszer-specifikus réteg: ESX (esx/), QB (qb/), közös
                logika (global/). Belépés: bridge/main.lua. Ide ne „saját
                szerver” workaround tömegesen; inkább standalone/overrides/.
client          Kliens oldal belépés: main.lua, exports.lua (publikus exportok
                regisztrációja; mérvadó névlista egy része).
server          Szerver oldal: main.lua, exports.lua, db_migrations.lua, db.lua,
                labor.lua, meta.lua – domain logika és exportok.
imports         Más resource-ból include-olható segédek: core.lua (FRAMEWORK,
                eCore, eCoreConfig minta), locale.lua, utils.lua, discordlog.lua.
libs            Megosztott könyvtár modulok: helper.lua (hf, eCore.helper), meta.lua,
                config_check.lua – nem keretrendszer-függő praktikumok.
locales         Fordítási fájlok (Config.locale és imports/locale.lua).
standalone      Erőforrás-specifikus, nem ESX/QB adapter: globális config,
                overrides (inventory, progress, core viselkedés), usableitem.lua.
html            NUI (ha a resource UI-t szolgál): ui.html, css, js, img.
docs            Projekt dokumentáció (checklist, AI referencia, terv, ez a fájl).
_installation_assist  Opcionális segédek telepítéshez vagy adatokhoz (nem runtime core).

Gyökér fájlok (fontosabbak)
----------------------------
fxmanifest.lua           Resource manifest (lua54, fájlok, függőségek, verzió).
.luarc.json              LuaLS (VS Code / Cursor) workspace beállítások.
.luacheckrc              Luacheck szabályok (CI + lokális futtatás).
.github/workflows/       Opcionális CI (pl. lua_ci.yml → validate_fxmanifest + luacheck).
scripts/                 CI / fejlesztői segéd: validate_fxmanifest.py (fxmanifest útvonalak).
types/                   LuaLS stub fájlok (---@meta; nem runtime).
changelog.md             Változásnapló; publikus API vagy export változáskor kötelező
                         frissítés.
export_examples_*.md     Gyors példák az exports.e_core hívásokra (kiegészíti a doksit).
README.md, README_HU.md  Emberi bevezető és linkek a Cursor / AI kontextushoz.

bridge/ részletek
-----------------
bridge/esx/       ESX bridge: client.lua, server.lua, shared.lua, config_defaults.lua, events/.
bridge/qb/        QB (dokumentáció szerint QBox kompatibilitás is): config_defaults.lua,
                  shared/client/server/events (ugyanilyen felosztás).
bridge/framework_config.lua  Keretrendszer választás (shared); lásd docs/FRAMEWORK_*.
bridge/global/    Keretrendszer-független közös rész: callbacks/, events/, client.lua,
                  server.lua, shared.lua.

standalone/ részletek
---------------------
standalone/config/       Globális Config és szintek: main.lua, levels.lua.
standalone/overrides/    Felülírások: inventory, progress, core, mozgás stb. Ide kerüljön
                         a szerver-specifikus vagy ritka stack illesztés; almappa = egy
                         integráció (példa: ox_inventory, qs_inventory).
standalone/usableitem.lua  Használható tárgy / usable item kapcsolódó logika (ha aktív).

client/ és server/ exports
----------------------------
Exportnevek és aláírások forrása: client/exports.lua, server/exports.lua, valamint a
bridge/main.lua exports( sorai; a dokumentációt ezekkel szinkronban tartandó.
