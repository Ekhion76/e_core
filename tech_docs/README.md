# e_core – technikai webdokumentáció (helykitöltő)

Itt építhető később a **publikus, kereshető** dokumentáció (például **Docusaurus**), ox_lib-szintű szerkezettel.

- **Szerződés és belső referencia** a repó gyökerében: `docs/INDEX_HU.md`
- **Új scaffold:** `npx create-docusaurus@latest tech_docs classic` (vagy a csapat által választott eszköz), majd a `docs/*.md` tartalmak átemelése / linkelése

A `tech_docs/docs/` mappa szándék szerint a generált oldal forrásait tartalmazza (Docusaurus frontmatter: `id`, `title`, `sidebar_position`).
